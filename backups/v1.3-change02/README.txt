GRADUATE CHAMPAIGN DECISION LAB — VERSION 1.3

Unzip this package, then open index.html in your browser.
Keep all web files together. No installation is required. Google Fonts supplies Montserrat and Source Sans Pro when online; approved Arial Black/Arial substitutes keep the tool usable offline.
For Netlify, upload this folder with index.html at its root.

Four pages: Performance, Decision, Payment, Definitions & formulas.
Designed around widescreen desktop presentation; small windows and increased browser zoom may scroll.
Scenario and reflection carry across pages in the same browser tab when session storage is available. Local file browser restrictions may affect this; hosted use is recommended for class delivery.

Uses fictional teaching data from the original prototype, with a fixed $38M baseline.

Browser-checked dashboard, navigation, decision feedback, payment reveal and reference switching. Calculation checks cover nine default-date scenarios and zero/completion cases.
